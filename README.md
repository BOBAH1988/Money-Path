# MoneyScope

PWA для учёта личных финансов, планирования бюджета и анализа расходов.

**Статус:** активная разработка  
**Страница бюджета:** `/budget`  
**Демо (GitHub Pages):** `https://BOBAH1988.github.io/Money-Path/`

---

## Стек технологий

- React 19 + TypeScript
- Vite (сборка и dev-сервер)
- React Router v7 (навигация)
- PWA (manifest.json, standalone mode)
- Vitest + oxlint (тесты и линтер)
- localStorage (хранение бюджета в браузере)

---

## Версионирование

Проект использует упрощённый SemVer: `0.0.X`

| Часть версии | Кто меняет | Когда |
|-------------|------------|-------|
| `0.0` (мажор.минор) | **Вы вручную** | В `package.json` при выходе большого релиза |
| `X` (патч) | **Автоматически** | При каждом `git commit` через pre-commit хук |

Текущая версия: **0.0.1**  
Каждый коммит увеличивает последнюю цифру на 1 (0.0.1 → 0.0.2 → 0.0.3 …).

> ⚠️ Если хотите сменить мажор или минор — отредактируйте `version` в `package.json` вручную, патч продолжит инкрементироваться от нового значения.

## Как запустить проект

### 1. Клонировать репозиторий
```bash
git clone https://github.com/BOBAH1988/Money-Path.git
cd Money-Path
```

### 2. Установить зависимости
```bash
npm install
```
> После `npm install` автоматически установится `pre-commit` хук, который увеличивает патч-версию перед каждым коммитом.

### 3. Запустить в режиме разработки
```bash
npm run dev
```
Откройте `http://localhost:5173/` и перейдите на вкладку **Бюджет**.

### 4. Собрать для продакшена
```bash
npm run build
```
Результат появится в папке `dist/`.

### 5. Предпросмотр сборки локально
```bash
npm run preview
```

### 6. Проверить линтер и тесты
```bash
npm run lint
npm test
```

## Страница бюджета (`/budget`)

На странице две таблицы:

1. **Ежемесячные расходы** — фиксированные траты (ипотека, продукты, связь и т.д.)
2. **Запланированные расходы** — разовые и плановые траты (развлечения, кредитка, буфер и т.д.)

### Что можно делать
- Редактировать название и сумму любой строки (клик по ячейке → ввод → Enter или потеря фокуса)
- Добавлять новую строку через поля внизу каждой таблицы + кнопка `+`
- Удалять строку кнопкой `×`
- Сбрасывать все значения к стандартным кнопкой «Сбросить к стандартному»

### Автосохранение
Все изменения сохраняются в `localStorage` браузера. Данные не пропадают после перезагрузки страницы.

### Автопересчёт
Строка **«Запланированные расходы»** в первой таблице подтягивает сумму автоматически из второй таблицы. Итоговая строка «Итого» тоже пересчитывается сама.

## Деплой на GitHub Pages

Проект уже настроен для автоматического деплоя через GitHub Actions.

### Что уже сделано
- `.github/workflows/deploy.yml` — собирает проект при пуше в `main`
- `vite.config.ts` — прописан `base: '/Money-Path/'` для корректных путей на GitHub Pages

### Как включить (один раз)
1. Откройте репозиторий на GitHub: `https://github.com/BOBAH1988/Money-Path`
2. Перейдите в **Settings → Pages**
3. В разделе **Build and deployment → Source** выберите **GitHub Actions**
4. Нажмите **Save**

После следующего пуша в `main` сайт будет доступен по адресу:
👉 `https://BOBAH1988.github.io/Money-Path/`

Статус сборки можно отслеживать во вкладке **Actions** репозитория.

## Основные ошибки и способы исправления

| Ошибка | Причина | Как исправить |
|--------|---------|---------------|
| `index.html` не открывается при двойном клике | Это Vite-проект, требует сборку/сервер | Используйте `npm run dev` или `npm run build` → `dist/index.html` |
| Белый экран на GitHub Pages | Не указан `base` в `vite.config.ts` | Добавьте `base: '/Money-Path/'` |
| Сборка падает в GitHub Actions | `npm ci` слишком строг к `package-lock.json` | В `deploy.yml` используется `npm install` |
| Версия не увеличивается при коммите | pre-commit хук не установлен | Запустите `npm install` (сработает `prepare`) |
| Стили не применяются | Кэш браузера | Жёсткая перезагрузка: `Ctrl + F5` / `Cmd + Shift + R` |
