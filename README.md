# Денежный путь

PWA для учёта личных финансов, планирования бюджета и анализа расходов.

**Статус:** активная разработка  
**Страница бюджета:** `/budget`  
**Демо (GitHub Pages):** `https://BOBAH1988.github.io/Money-Path/`

---

## Стек технологий

- React 19 + TypeScript
- Vite (сборка и dev-сервер)
- React Router v7 (навигация)
- PWA (manifest.json, standalone mode)
- Vitest + oxlint (тесты и линтер)
- Firebase Auth + Firestore (синхронизация между устройствами)
- localStorage (офлайн-хранение и кэш при недоступности Firebase)

---

## Версионирование

Проект использует упрощённый SemVer: `0.0.X`

| Часть версии | Кто меняет | Когда |
|-------------|------------|-------|
| `0.0` (мажор.минор) | **Вы вручную** | В `package.json` при выходе большого релиза |
| `X` (патч) | **Автоматически** | При каждом `git commit` через pre-commit хук |

Текущая версия: **0.0.140**  
Каждый коммит увеличивает последнюю цифру на 1 (0.0.1 → 0.0.2 → 0.0.3 …).

> ⚠️ Если хотите сменить мажор или минор — отредактируйте `version` в `package.json` вручную, патч продолжит инкрементироваться от нового значения.

## Как запустить проект

### 1. Клонировать репозиторий
```bash
git clone https://github.com/BOBAH1988/Money-Path.git
cd Money-Path
```

### 2. Установить зависимости
```bash
npm install
```
> После `npm install` автоматически установится `pre-commit` хук, который увеличивает патч-версию перед каждым коммитом.

### 3. Запустить в режиме разработки
```bash
npm run dev
```
Откройте `http://localhost:5173/` и перейдите на вкладку **Бюджет**.

### 4. Собрать для продакшена
```bash
npm run build
```
Результат появится в папке `dist/`.

### 5. Предпросмотр сборки локально
```bash
npm run preview
```

### 6. Проверить всё перед коммитом
```bash
npm run check
```

Esta команда последовательно запускает:
1. `npm run lint` — проверка кода линтером
2. `npm test` — запуск всех автотестов
3. `npm run build` — проверка TypeScript и сборка Vite

Если одна из проверок упадёт — исправьте ошибку перед коммитом.

Отдельно можно запустить:
```bash
npm run lint
npm test
npm run build
```

> 🧪 **Автотесты:** покрывают логику бюджета, хуки, компоненты и страницы. Тесты запускаются при каждом коммите и на GitHub Actions.

## Страницы приложения

| Путь | Описание |
|------|----------|
| `/` | Дашборд |
| `/budget` | Планирование бюджета (ежемесячные + запланированные расходы) |
| `/assets` | Активы |
| `/liabilities` | Пассивы |
| `/income` | Доход |
| `/income-archive` | Доходы архив |
| `/import` | Импорт/экспорт данных (всплывающее окно из меню) |

### Страница бюджета (`/budget`)

На странице две таблицы:

1. **Ежемесячные расходы** — фиксированные траты (ипотека, продукты, связь и т.д.)
2. **Запланированные расходы** — разовые и плановые траты (развлечения, кредитка, буфер и т.д.)

### Что можно делать
- Редактировать название, сумму по факту и план на следующий месяц любой строки
- Добавлять новую строку через кнопку `+` в заголовке таблицы
- Удалять строку кнопкой `×`
- Сбрасывать все значения к стандартным кнопкой «Сброс на стандартные» в меню
- Сворачивать/разворачивать таблицу «Запланированные расходы»

### Автосохранение
Все изменения сохраняются в Firestore под текущим пользователем и дублируются в `localStorage`. При отсутствии интернета данные читаются и пишутся в `localStorage`, при восстановлении соединения — синхронизируются с Firebase.

## Авторизация и аккаунт

### Вход / регистрация
Кнопка «Аккаунт» (👤) в верхней панели открывает окно:
- **Вход** — email + пароль
- **Регистрация** — email, пароль, подтверждение пароля, чекбоксы согласия с правилами и cookie
- **Восстановление пароля** — ссылка по email
- **Подтверждение почты** — письмо отправляется после регистрации

### Требования к паролю
- Минимум 8 символов
- Заглавная буква, строчная буква, цифра

### Аккаунт (после входа)
В меню аккаунта отображается:
- Email пользователя
- Роль (Администратор — для `79042044926@ya.ru`)
- Кнопка «Выйти»
- Для администратора — кнопка «Аналитика»

### Аналитика (только администратор)
Статистика пользователей: всего зарегистрировано, активных, новых за 30 и 7 дней.

## Синхронизация между устройствами

Данные каждого пользователя хранятся в Firestore по пути `users/{userId}/{collection}`. Правила безопасности ограничивают доступ: пользователь видит и редактирует только свои данные.

Чтобы синхронизация заработала:
1. В Firebase Console → Authentication включить **Email/Password**
2. В Firestore → Правила опубликовать правила доступа по `userId`
3. Войти в приложение под своим аккаунтом — локальные данные автоматически переедут в Firestore

## Импорт / экспорт данных

Кнопка «Импорт» в меню открывает всплывающее окно с кнопкой **«Импорт данных»**. Скачивает все данные пользователя в файл JSON (`denegnyj_put_<userId>_<дата>.json`), который можно передать аналитику или наставнику. В файл входят: активы, пассивы, доход, доходы архив, план бюджета.

---

## Правила оформления таблиц (общее соглашение)

Все таблицы в приложении следуют единому шаблону через компонент `BudgetTable`:

1. **Обёртка** — `<section className="budget-card">` с заголовком
2. **Строки** — имя, сумма, план, действия (редактирование `✎`, удаление `×`)
3. **Итог** — автоматический пересчёт сумм
4. **Форматирование** — пробел как разделитель тысяч, валюта `₽`
5. **Заголовок страницы** — через `PageTitleContext`

## Деплой на GitHub Pages

Проект настроен для автоматического деплоя через GitHub Actions.

### Что уже сделано
- `.github/workflows/deploy.yml` — собирает проект при пуше в `main`
- `vite.config.ts` — прописан `base: '/Money-Path/'` для корректных путей на GitHub Pages

### Как включить
1. Откройте репозиторий на GitHub: `https://github.com/BOBAH1988/Money-Path`
2. Перейдите в **Settings → Pages**
3. В разделе **Build and deployment → Source** выберите **GitHub Actions**
4. Нажмите **Save**

После следующего пуша в `main` сайт будет доступен по адресу:
👉 `https://BOBAH1988.github.io/Money-Path/`

## Основные ошибки и способы исправления

| Ошибка | Причина | Как исправить |
|--------|---------|---------------|
| `index.html` не открывается при двойном клике | Это Vite-проект, требует сборку/сервер | Используйте `npm run dev` или `npm run build` → `dist/index.html` |
| Белый экран на GitHub Pages | Не указан `base` в `vite.config.ts` | Добавьте `base: '/Money-Path/'` |
| Сборка падает в GitHub Actions | `npm ci` слишком строг к `package-lock.json` | В `deploy.yml` используется `npm install` |
| Версия не увеличивается при коммите | pre-commit хук не установлен | Запустите `npm install` (сработает `prepare`) |
| Стили не применяются | Кэш браузера | Жёсткая перезагрузка: `Ctrl + F5` / `Cmd + Shift + R` |
| Данные не синхронизируются между устройствами | Firebase не настроен | Включите Email/Password в Authentication, настройте правила Firestore, войдите в аккаунт |
