# Журнал изменений (Changelog)

## [0.0.148] — 06.11.2026

### Исправлено
- Приложение работает без блокировки Firebase — режим гостя загружается сразу
- AuthProvider больше не блокирует рендеринг, пока Firebase не ответит
- loading всегда false — приложение показывается сразу (режим гостя)
- Пользователь из Firebase подгружается асинхронно без блокировки UI
- Кнопка меню и кнопка аккаунта работают без авторизации

## [0.0.147] — 06.11.2026

### Исправлено
- Приложение полностью рабочее без Firebase Auth и без входа
- loadFromFirestore без userId загружает из локального localStorage
- loadBudgetPlan без userId загружает стандартный бюджет из localStorage
- saveBudgetPlan/resetBudgetPlan без userId работают с localStorage
- Приложение рабочее офлайн; при входе в аккаунт данные синхронизируются с Firestore
