# Журнал ключевых ошибок и исправлений

Журнал фиксирует значимые дефекты приложения, их причины и внесённые изменения. Это технический журнал проекта, а не полный перечень пользовательских обращений или инцидентов безопасности. Даты отражают историю изменений, описанную в проектной документации; если точный commit для старого исправления не указан, SHA не приводится.

## Исправления

| Дата | Симптом / влияние | Причина | Исправление и проверка |
|---|---|---|---|
| 6–8 ноября 2026 | Гостевой режим показывал пустые списки или интерфейс не открывал вход для неавторизованного пользователя. | Загрузка данных была связана с авторизацией; кнопка аккаунта могла открывать меню, которое ничего не показывало для гостя. | Гостевые данные читаются из локального хранилища; форма входа открывается отдельно от меню аккаунта. Добавлены тесты и проверки UI. |
| 8 ноября 2026 | Итоги бюджета могли не обновиться после редактирования; отдельные действия удаления были недоступны. | Итог использовал устаревшее значение из замыкания, а строка бюджета не предоставляла действие удаления во всех режимах. | Итоги вычисляются из актуальных записей; удаление доступно с подтверждением. Покрыто тестами расчётов и компонентов бюджета. |
| 8–10 ноября 2026 | Данные разных устройств могли перезаписывать или удалять изменения друг друга; после сетевой ошибки удалённая запись могла появиться снова. | Сохранение/очистка коллекции затрагивали набор документов целиком, а не сохраняли каждую незавершённую операцию независимо. | Запись, удаление и очистка ставятся в устойчивую локальную очередь по аккаунту и отправляются поэлементно. Ошибка синхронизации не должна превращаться в пустую коллекцию; незавершённая операция остаётся для повторной отправки. Проверяется unit-тестами и emulator-тестами Firestore Rules / multi-client sync. |
| 9 ноября 2026 | Первый экран задерживался из-за ожидания Firebase; при синхронизации плана бюджета возникала ошибка `t.map is not a function`. | Инициализация/загрузка Firestore блокировала первичный показ данных; запись плана `{ items, updatedAt }` попадала в обработчик массива записей. | Используется local-first загрузка с отложенным сетевым обновлением; план синхронизируется отдельной операцией, а не как коллекционный массив. Проверяется тестами синхронизации и сборкой. |
| 9–10 ноября 2026 | После изменения юридических документов существующий аккаунт мог продолжать работу со старой редакцией; у пользователя не было самостоятельного полного удаления аккаунта. | Не было проверки сохранённых версий документов и последовательности удаления данных аккаунта. | Добавлен блокирующий запрос повторного согласия после проверки серверного профиля. Удаление требует повторной аутентификации, удаляет облачные и локальные данные и аккаунт Firebase; предусмотрены сообщения для частичного сбоя. Проверяется тестами согласия, очистки локальных данных и Firestore Rules. |
| 10 ноября 2026 | Браузер выводил предупреждение об устаревшем `apple-mobile-web-app-capable`. | Для совместимости с Apple присутствовал iOS-метатег, но отсутствовал общий метатег установки веб-приложения. | Добавлен `<meta name="mobile-web-app-capable" content="yes" />`; Apple-метатег сохранён для iOS. |
| 10 ноября 2026 | Dependabot сообщил об уязвимом `@grpc/grpc-js@1.9.16` в транзитивных зависимостях Firebase. | `@firebase/firestore@4.19.1` объявляет диапазон `~1.9.0`, хотя исправленная версия начинается с `1.13.6`. | Добавлен scoped npm override только для `@firebase/firestore`, разрешающий `@grpc/grpc-js` `^1.13.6`; lockfile использует `1.14.7`. `npm audit`, `npm audit --omit=dev`, `npm run check` и Firestore emulator tests прошли. Override нужно убрать после совместимого обновления Firebase/Firestore. |
| 10 ноября 2026 | GitHub Secret scanning обнаружил Google API key в `src/lib/firebase.ts`. | Firebase API key был встроен в исходный код как fallback-конфигурация. | Удалён fallback, инициализация Firebase требует `VITE_FIREBASE_API_KEY`; без него возвращается явная ошибка конфигурации. Ключ нужно заменить или ограничить в Google Cloud Console: изменение файла не отзывает опубликованный ключ и не удаляет его из Git-истории. |

## Открытые предупреждения и известные ограничения

| Дата проверки | Наблюдение | Состояние / действие |
|---|---|---|
| 10 ноября 2026 | Firebase/Firestore по-прежнему объявляет для `@grpc/grpc-js` диапазон `~1.9.0`, не включающий исправленную версию. | Scoped npm override решает уязвимость на уровне lockfile, но временно выходит за объявленный Firestore диапазон. | Следить за совместимым обновлением Firebase/Firestore, после которого удалить override и повторить аудит и тесты. Подробности и история Dependabot — в [`security.md`](security.md). |
| 10 ноября 2026 | В том же логе Dependabot показал notice о будущем переходе `ubuntu-latest` на более новую Ubuntu. | Информационное уведомление GitHub Actions runner image; оно не вызвало ошибку Dependabot и не повлияло на деплой. |
| 10 ноября 2026 | Сборка может сообщать о крупном Firestore JavaScript chunk и о lint-предупреждениях в существующих компонентах/эффектах. | Это предупреждения производительности/качества, не ошибки сборки. Оценивать при изменении соответствующих модулей и следить за влиянием на время загрузки. |
| 10 ноября 2026 | Локальный Firebase Emulator требует Java 21 или новее в используемой CI-версии Firebase CLI. | На рабочих станциях запускайте эмулятор с JDK 21+; CI задаёт Java 21 отдельно. |

## Как добавлять запись

Для существенного исправления добавляйте строку с датой, пользовательским симптомом, подтверждённой причиной, решением и фактической проверкой. Не включайте в журнал email, финансовые суммы, содержимое архивов, токены или другие данные пользователей. Если причина ещё не установлена, укажите её как гипотезу, а не как подтверждённый факт.
